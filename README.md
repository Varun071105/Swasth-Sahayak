🩺 Swasth Sahayak

🚀 Features

🤖 Symptom Checker: Identify possible conditions based on user-entered symptoms.

🕒 Health Reminders: Set medicine and appointment reminders with real-time alerts.

📍 Doctor & Clinic Finder: Locate verified doctors and clinics near your area.

💊 Health Tips & Education: Get AI-curated wellness insights and daily advice.

📈 User Dashboard: Track health logs, reminder history, and recommendations.

🧠 Tech Stack
Layer	Technologies
Frontend	React.js, Tailwind CSS
Backend	Node.js, Express.js
Database	MongoDB
APIs / Integrations	Medical API (disease info, medicine search), Notification Service
Other Tools	JWT Authentication, RESTful API design
⚙️ Installation & Setup
# Clone the repository
git clone https://github.com/Varun071105/Swasth-Sahayak.git

# Navigate into the folder
cd Swasth-Sahayak

# Install dependencies
npm install

# Start backend server
npm run server

# Start frontend
npm start


By default:

Frontend runs on http://localhost:3000

Backend runs on http://localhost:5000
